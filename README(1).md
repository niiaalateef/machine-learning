# 🤖 ML-Based Obstacle Avoidance Robot

> **Machine Learning + Robotics + Pygame Simulation**

An intelligent robot simulation that uses **Machine Learning to make
movement decisions from virtual sensor data** instead of relying only on
fixed obstacle-avoidance rules.

## 🌟 Project Overview

**📡 Sensor Data → 🧠 ML Model → 🎯 Action → 🤖 Robot Movement**

The robot is simulated in a **2D Pygame environment** with three virtual
distance sensors:

-   🟢 Left
-   🔵 Front
-   🟣 Right

The ML task predicts:

  Action         Meaning
  -------------- --------------
  ⬆️ `FORWARD`   Move forward
  ⬅️ `LEFT`      Turn left
  ➡️ `RIGHT`     Turn right
  🛑 `STOP`      Stop

## 🎯 Objectives

-   Generate thousands of simulated sensor readings.
-   Train and compare multiple Machine Learning classifiers.
-   Evaluate accuracy, precision, recall, F1 score, and confusion
    matrices.
-   Use a trained model as the robot's decision-making brain.
-   Build an autonomous 2D robot simulation.
-   Measure navigation and inference performance.

## 🧠 Machine Learning Models

The project trains four classifiers:

-   🔷 **K-Nearest Neighbors (KNN)**
-   🌳 **Decision Tree**
-   ⚡ **Support Vector Machine (SVM)**
-   🌲 **Random Forest**

## 📊 Dataset

The dataset is generated automatically with **5,000 simulated sensor
samples**.

**Features:**

``` text
left
front
right
```

**Target:**

``` text
action
```

Example:

``` text
left   front   right   action
80     80      70      FORWARD
20     80      70      LEFT
70     80      20      RIGHT
20     10      20      STOP
```

> ⚠️ The dataset is synthetic. Its labels come from the project's
> generated labeling logic, so high classification scores show that the
> models learned those patterns well; they do not by themselves prove
> real-world robot performance.

## 🎮 Robot Simulation

The robot is simulated using **Pygame**.

  Visual              Meaning
  ------------------- -----------------
  🔵 Blue circle      Robot
  🔴 Red rectangles   Obstacles
  🟡 Yellow circle    Target
  🟢 Green lines      Virtual sensors

The autonomous loop is:

``` text
Read Sensors
     ↓
ML Prediction
     ↓
Safety / Obstacle Check
     ↓
Steer Toward Target
     ↓
Move Robot
     ↓
Repeat
```

The current simulator combines ML obstacle-avoidance predictions with a
safety layer and target-directed navigation.

## 💡 Important ML Insight

The current model learns obstacle-avoidance actions from:

``` text
left + front + right
```

The yellow target is not part of the original training features.
Therefore, target-seeking is currently handled by navigation/safety
logic alongside the ML obstacle-avoidance model.

A future version can add:

``` text
left
front
right
target_direction
target_distance
```

This would allow the ML model to learn both:

**🚧 obstacle avoidance + 🎯 goal navigation**
